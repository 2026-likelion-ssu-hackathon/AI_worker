# 시연 대본 — 처음부터 끝까지 한 흐름

**이 문서 하나만 보고 진행한다.** 위에서 아래로 읽으면서 그대로 타이핑한다.
리허설(2026-08-19)과 배포 QA(2026-08-20)에서 검증된 대사 그대로다 — **괄호 안 낱말을
바꾸지 말 것.** 게이트·트리거가 그 낱말을 본다. 준비 점검(API 키·Railway·환경변수)은
`demo-checklist.md`, 이 문서는 진행만 담는다.

---

## 시작 전 — 두 창을 연다

| 창 | 주소 | 역할 |
| --- | --- | --- |
| **A** | `www.momote.site/?roomId=1&userId=1` | 여자친구 역 |
| **B** | `www.momote.site/?roomId=1&userId=2` | 남자친구 역 |

- 두 창 다 ①번 줄(감정 상태)이 떠 있는지 확인. 비어 있으면 백엔드 쪽 문제다
- **직전 5분 안에 리허설로 영상 카드를 띄웠다면** 막 2가 쿨다운 백스톱에 걸린다 — 5분 기다린다
- 대사 어디에도 **'유튜브' 낱말 금지**(아무것도 안 하고 장면만 흐려짐),
  막 4 전까지 **'데이트' 낱말 금지**(코스 카드가 미리 떠서 장면이 섞임)

**기다리는 감각** — 이걸 몸에 익혀야 시연이 안 급해진다:

| | 반영 시간 |
| --- | --- |
| ①번 줄 (감정) | 6~8초 + 폴링 4.5초 |
| ②번 줄 (카드) | 12~15초 + 폴링 (영상 카드는 리허설 실측 3.8초로 더 빨랐다) |

**카드가 안 떴는데 다음 막으로 넘어가지 않는다.** 안 뜨면 각 막의 백업 대사를 쓴다.

## 막 1 — 평온 (기본 상태를 먼저 보여준다)

| 창 | 대사 |
| --- | --- |
| A | 오늘 재택으로 했어 |
| B | 응 그랬구나 |
| A | 점심은 그냥 집에 있는 거 먹었어 |
| B | 나도 대충 먹었어 |

**기대 결과** → 양쪽 ①번 줄 **"평온해요"** (무채색, 축 늘어진 곡선).

**짚는 멘트**: "카카포는 평소엔 이렇게 조용히 지켜만 봅니다."

> ⚠️ 애드리브로 감탄·들뜸·맛 표현("진짜 맛있더라")을 섞으면 활기 점수가 올라
> "신나 보여요"(초록)가 된다. **철저히 밋밋하게.**

## 막 2 — 냉각기 유튜브 (개별 노출을 여기서 보여준다)

싸운 다음 날 서먹한 상황. 부드러운 고민 어휘(답답해·미안한·모르겠어)가 트리거다.
**마지막 발화를 공격적으로 바꾸면 말투 교정이 대신 발동해 영상이 보류된다** — 대본대로
순화된 채로 끝낸다.

| 창 | 대사 |
| --- | --- |
| A | 어제 일은 나도 좀 생각해봤어 |
| B | 응 나도 |
| A | 연락 문제로 이렇게 부딪히는 게 처음이 아니라서 그게 좀 (답답해) |
| B | (미안한) 건 맞는데 나도 어떻게 말해야 할지 (모르겠어) |
| A | 나도 뭐라고 해야 할지 잘 모르겠어서 계속 미루고 있었어 |
| B | 천천히 얘기해보자 오늘은 좀 쉬고 |

**기대 결과** →
- **B 화면에만** 영상 카드 (리허설 실측: "평생 써먹는 진심으로 사과하는 법" +
  "현재 겪고 있는 상황과 비슷한 내용을 다룬 영상이에요")
- **A 화면엔 안 뜬다** — 두 창을 나란히 비추면서 이걸 보여준다
- 양쪽 ①번 줄은 서운/쌓임 계열(파랑)로 같이 바뀐다

**짚는 멘트**: "사과하고 싶어하는 쪽에게만 조용히 건넵니다. 상대는 이런 게 떴다는 사실
자체를 모릅니다 — 지적이 노출되면 그게 또 싸움거리가 되니까요. 그리고 이 영상, 제목만
보고 고른 게 아니라 베스트 댓글 3개까지 읽고 골랐습니다."

> 🔧 **영상이 안 뜨면** (배포 QA 실측 — "답답해" 줄에 말투 교정이 먼저 발동하는 편차가
> 있다) **B 창으로 이 문장을 이어 친다:**
>
> **"미안한 마음은 큰데 어떻게 화해를 해야 할지 잘 모르겠어"**
>
> QA 에서 발동 확인된 백업 대사다. 이것도 안 뜨면 직전 5분 쿨다운을 의심하고
> 이 막은 건너뛴다 — 멈춰 서지 않는다.

## 막 3 — 말투 교정 → 안전장치 (붙여서 보여주는 게 이 시연의 핵심)

### 3-1. 진짜 갈등 — 교정 카드가 뜬다

| 창 | 대사 |
| --- | --- |
| A | 오빠 오늘 몇 시에 와? 저녁 같이 먹으려고 기다리고 있었어 |
| B | 아 미안 오늘 야근 잡혀서 못 갈 것 같아 |
| A | 또? 지난주에도 그랬잖아 |
| B | 진짜 미안해 다음엔 꼭 갈게 |
| A | (야 너는 맨날 그런 식이야.) ← **마침표까지 그대로** |

**기대 결과** → **A 화면에만** 교정 카드 (상황 진단 + "대신 이렇게 상대방에게
말해보세요." + 대체 문장 + 이유). **B 화면엔 아무것도 없다.**
①번 줄은 양쪽 다 "감정이 올라와요"(빨강)로.

**짚는 멘트**: "공격적인 메시지를 보낸 사람에게만, 보낸 직후에 제안합니다.
상대방 화면엔 아무것도 없습니다."

### 3-2. 같은 비속 표현, 장난 — 아무것도 안 뜬다

> ⏸️ **여기서 한 템포(수십 초) 쉰다.** 직전 싸움 맥락이 붙어 있으면 "와 미친 ㅋㅋㅋ"에
> 오탐이 날 수 있다 (배포 QA 실측 — 4회 중 1회 편차). 관객에게 카드 내용을 설명하면서
> 자연스럽게 시간을 번다.

| 창 | 대사 |
| --- | --- |
| A | 나 오늘 지각해서 팀장님한테 엄청 혼났어 ㅋㅋㅋ |
| B | 와 미친 ㅋㅋㅋ 또 늦었어? |
| A | ㅋㅋㅋ 알람 세 개 다 껐대 내가 기억도 안 나 ㅋㅋ |
| B | 야 이 바보야 ㅋㅋ |

**기대 결과** → **아무것도 안 뜬다.** ②번 줄 양쪽 다 비어 있다.

**짚는 멘트**: "'미친', '야 이 바보야' — 아까랑 똑같이 거친 말인데 이번엔 침묵합니다.
어휘 필터가 아니라 맥락 판정이라서요."

> ⚠️ **"아무것도 안 뜬다"고 단언하기 전에 B 화면을 눈으로 확인한다.** 오탐이 나면
> 카드는 "와 미친" 화자인 **B 화면에** 뜬다 — A 화면만 비추고 있으면 관객은 모르지만,
> 확인 없이 단언했다가 들키면 신뢰가 깨진다. 떠 있으면 "장난엔 안 뜨는 게 기본인데
> 방금 싸움 직후라 경계를 높게 잡았네요"로 넘긴다.

## 막 4 — 데이트 코스 (RAG + 실재 장소)

| 창 | 대사 |
| --- | --- |
| A | 아 배고프다 뭐 먹지 |
| B | 이번 주말에 (성수)에서 (데이트)할까? |

**기대 결과** → **양쪽 화면**에 코스 카드 (실측 12~13초). 실제 가게 3곳
(밥 → 구경 → 카페) + 카카오맵 링크 + 추천 이유.

**짚는 멘트**: "장소는 전부 카카오맵에 실재하는 가게고 링크가 진짜 열립니다. AI 가
지어낸 게 아니라, AI 는 '무엇을 찾을지'만 정하고 장소는 카카오가 줍니다. 그리고 추천
이유를 보시면 — 예전에 이 커플이 나눈 대화를 기억하고 있다가 근거로 씁니다."
(배고픔 언급이 앞에 있어서 추천 이유가 시드 기억 — 마라탕·크림파스타 — 을 인용할
확률이 높다. 인용이 나오면 그 문장을 소리 내어 읽어준다.)

## 막 5 — 애정 마무리

| 창 | 대사 |
| --- | --- |
| B | 그래도 오늘 이렇게 얘기하니까 좋다 (사랑해) |

**기대 결과** → 양쪽 ①번 줄이 **"다정해 보여요"**(핑크, 하트 매듭)로.

**짚는 멘트**: "싸우고, 화해하고, 데이트 약속까지 — 위젯이 대화의 흐름을 처음부터
끝까지 따라왔습니다."

> ⚠️ **막 3에서 애드리브로 싸움을 길게 끌었다면 여기서 격앙이 안 풀릴 수 있다.**
> 상태 채점은 마지막 6발화만 본다(`SCORE_RECENT`). 대본대로면 분노 발화(1건)가 정확히
> 창 밖으로 밀려나 있다 — 분노 발화를 여러 건 쳤으면 막 4 뒤에 밋밋한 대사를 두어 줄
> 더 치고 나서 "사랑해"를 보낸다.

> ⚠️ **막 3의 교정 카드가 A 화면 ②번 줄에 여기까지 남아 있다** (2026-08-20 리허설 실측).
> 프론트가 카드를 "트리거가 최근 15건 안"까지 유지해서, 대본 분량으로는 막 5 까지
> 안 내려간다 — 종류별 유지 창(교정만 3건 + 45초)을 민상님께 제안해 둔 상태
> (`design.md` 2부 13장). **프론트 수정 전이면 이 장면은 카드가 없는 B 화면을 비춘다** —
> ①번 줄은 양쪽이 같아서 마무리 멘트에 지장이 없다.

## 대안 시나리오 2종 — 배포 실측 검증 완료 (2026-08-20 밤)

기존 막 1~5 대신 (또는 추가로) 쓸 수 있는 두 흐름. **대사 전부 배포 환경에 실제
타이핑해서 단계별 라벨·카드를 확인했다.** 괄호 낱말 유지, 메시지 간 5초 안팎.

### 시나리오 A — 평온 → 서운(영상) → 분노(교정) · 3분

**1) 평온** → 양쪽 ① "평온해요" (실측 ✅)

| | 대사 |
| --- | --- |
| A | 오늘 하루 그냥 무난했어 |
| B | 나도 별일 없었어 |
| A | 저녁은 대충 챙겨 먹으려고 |
| B | 응 나도 간단하게 먹을래 |

**2) 서운 + 냉각기 영상** → 양쪽 ① "서운해 보여요" + **영상 카드 한쪽 화면에만** (실측 ✅)

| | 대사 |
| --- | --- |
| A | 어제 일 생각하면 아직 마음이 좀 무거워 |
| B | 나도 계속 신경 쓰였어 |
| A | (서운)했던 게 잘 안 풀리네 어떻게 말해야 할지 (모르겠어) |
| B | (미안해) 나도 어떻게 풀어야 할지 몰라서 말을 못 꺼냈어 |
| A | 오늘은 일단 각자 좀 생각해보자 |

> ⚠️ "고마워" 같은 풀어지는 말을 넣으면 ① 이 "다정해 보여요"로 가버린다 (실측 —
> 1차 대본이 그랬다). 서운함이 **해소되지 않은 채** 끝나야 파란 매듭이 나온다.
> 영상이 어느 화면에 뜨는지는 LLM 이 정한다 — **뜬 쪽 화면을 비추면 된다**
> (실측에서는 서운함을 말한 쪽이었다). 직전 5분 안에 영상이 나갔으면 보류.

**3) 분노 + 말투 교정** → 양쪽 ① "감정이 올라와요" + **교정 카드는 화낸 쪽에만** (실측 ✅)

| | 대사 |
| --- | --- |
| B | 근데 오늘도 야근이라 늦을 것 같아 |
| A | 또? 어제도 그랬잖아 |
| B | 미안 진짜 어쩔 수 없었어 |
| A | (야) 너는 (맨날) 일이 먼저야(.) ← 마침표까지 |

### 시나리오 B — 신남 → 데이트 코스 → 애정 · 2분

**1) 신남** → 양쪽 ① "신나 보여요" (실측 ✅ — 시나리오 A 직후여도 완충 두어 줄 +
이 4줄이면 격앙이 채점 창 밖으로 밀려난다, 실측)

| | 대사 |
| --- | --- |
| B | 나 이번주 금요일에 연차 냈어!! |
| A | 헐 대박 잘됐다 ㅋㅋㅋ |
| B | 그니까 완전 신나 ㅋㅋ 하루가 통째로 비어 |
| A | 오 그럼 오랜만에 놀러 가자 |

**2) 데이트 코스** → **양쪽 화면**에 코스 카드 (실측 ✅ — "성수 서울숲 데이트 코스",
실장소 3곳 + 카카오맵 링크, 12초대)

| | 대사 |
| --- | --- |
| B | 그럼 우리 금요일에 (성수)에서 (데이트)할까? |
| A | 좋아 성수 완전 좋지 |

**3) 애정 마무리** → 양쪽 ① "다정해 보여요" (실측 ✅)

| | 대사 |
| --- | --- |
| B | 이렇게 같이 계획 세우니까 참 좋다 |
| A | 나도. 너랑 이런 시간 보내는 게 제일 편하고 좋아 |
| B | (사랑해) 그날 봐 |

> ⚠️ 마무리 대사에 "금요일에 보자"를 쓰지 말 것 — 일정 확정 트리거가 코스 카드를
> 한 장 더 태워서 애정 장면을 덮는다 (실측). "그날 봐"는 안 걸린다.
> 들뜬 말(ㅋㅋ·신나)을 마무리에 섞으면 활기가 애정을 이겨 "신나 보여요"가 유지된다 —
> 차분한 애정 표현으로 끝내야 핑크가 나온다.
